# chem-lab-automation
Automated program for complex chemistry lab experiment calculations.  
This project aims to automate labour-intensive calculations involved in certain chemistry experiments.

## Scope and Aim  
Aim: automate personal labour  
Scope: uncertain, possible HTML5/CSS inclusion in the future
## Current support  
Currently only supports *Experiment-1:Thermodynamic functions from EMF measurements: Zn-Cu system* in *BACHY105 Applied Chemistry Lab Manual*  
## Tech Stack  
Back-end: Python(output through terminal)
