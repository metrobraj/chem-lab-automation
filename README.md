# chem-lab-automation
Automated program for complex chemistry lab experiment calculations.  
This project aims to automate labour-intensive calculations involved in certain chemistry experiments FOR BACHY105 Applied Chemistry Lab Manual 2026.

## Scope and Aim  
Aim: automate personal labour 
Scope: possible HTML5/CSS inclusion in the future, despite short-term scope.
## Current support  
Currently supports **BACHY105 Lab Manual 2026**:  
*Experiment-1: Thermodynamic functions from EMF measurements: Zn-Cu system*
*Experiment-2: Determination of reaction rate, order, and molecularity - ester hydrolysis*
*Experiment-4: Analysis of iron in carbon steel by potentiometry*
